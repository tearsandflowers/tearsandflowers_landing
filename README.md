# tearsandflowers_landing

Landing page for my musical project.

## Viewing locally

Serve the repository with any static file server. For example using Python:

```bash
python3 -m http.server
```

Then open `http://localhost:8000/index.html` in your browser.

All fonts, images and video assets are included in the repo.

## Deployment

You can host the page with GitHub Pages by enabling Pages for this repository.
